\chapter*{Resumen}
%\begin{center}
%\Large{\bft{Resumen}}
%\end{center}
%\vskip0.5cm

CVN constituye la norma española de referencia para representar
información curricular de investigadores, mantenida por la Fundación
Española para la Ciencia y la Tecnología (FECYT). Sin embargo, la
existencia de este formato normalizado no elimina el coste de crear,
mantener y adaptar currículos: su representación XML oficial y la
herramienta oficial asociada no están pensadas como base directa de
aplicaciones abiertas y ligeras, y el paquete oficial reúne fuentes
heterogéneas (manuales, modelos técnicos y tablas auxiliares) cuyo uso
automatizado exige un análisis previo.

Este Trabajo Fin de Grado presenta Open CVN, una arquitectura
computacional abierta que separa la interoperabilidad estructural del
significado curricular sin perder trazabilidad hacia las fuentes
oficiales. El sistema genera de forma reproducible bindings estructurales
a partir de los esquemas XSD del ecosistema CVN, normaliza los metadatos
dispersos entre el manual funcional y el modelo en árbol, aplica una
política semántica conservadora respaldada por evidencia concreta de cada
tabla de valores controlados, y deriva de ella un modelo de dominio y un
modelo conceptual agnóstico. Sobre esa base se define un formato de
intercambio abierto, Open CVN JSON, junto con un parser, un validador y
mecanismos de importación desde CVN XML y CVN PDF, con una vía
determinista prioritaria y un recurso opcional a modelos de lenguaje de
gran tamaño cuando esta no resulta suficiente. Una herramienta local de
gestión, de línea de órdenes, demuestra el uso completo de esta
representación: almacenamiento, versionado de currículos maestro y
derivados, y exportación a JSON, LaTeX y PDF.

El sistema se evalúa mediante una batería de 488 pruebas automatizadas y
reproducibles, organizada según las mismas capas de la arquitectura, que
se ejecuta también en integración continua ante cada contribución
propuesta. Los resultados confirman garantías fuertes allí donde el
proceso es determinista (generación estructural, normalización, política
semántica y validación del formato) y garantías parciales, documentadas
de forma explícita, en la importación de CVN XML y en la importación
asistida por modelos de lenguaje.
